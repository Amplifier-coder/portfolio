# Project screenshots

Save your screenshots in this folder using these names:

- `enterprise-ai-chatbot.png`
- `food-delivery-system.png`

The portfolio automatically displays each image on its project card and a larger
version in **Explore project**. Until an image is available, the card displays
“Project screenshot coming soon”.

For JPG or WebP files, update the corresponding image `src` in `index.html` to
match the actual filename. Update its `alt` text to describe what the screenshot shows.

To add more screenshots to a project, duplicate its `project-screenshot` figure
inside the same project card and change the filename and alt text.
